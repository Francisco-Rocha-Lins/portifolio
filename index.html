O FUTURO DA TECNOLOGIA

Tendências Tecnológicas

Conheça algumas tecnologias que estão transformando o mercado e criando novas oportunidades na área de TI.

01

Cibersegurança

Área responsável por proteger sistemas, redes e dados contra ataques digitais, garantindo a segurança e a privacidade das informações.

02

Blockchain

Tecnologia que registra informações em blocos conectados, oferecendo transparência, segurança e maior confiabilidade aos dados.

03

Automação e Robótica

Utiliza sistemas e máquinas para executar tarefas automaticamente, aumentando a eficiência e reduzindo atividades repetitivas.

04

Edge Computing

Permite processar dados próximos de onde são produzidos, reduzindo atrasos e melhorando o desempenho de dispositivos conectados.

PROJETO 01 | PROJETO REAL

ATACATUDO

Sistema de controle de armazenamento desenvolvido em sala de aula para o comércio Horti Paraíba. O projeto teve como objetivo desenvolver uma solução para auxiliar na organização e no gerenciamento dos produtos armazenados.

Foi desenvolvido utilizando diferentes tecnologias, integrando programação e banco de dados para construir uma solução voltada a uma necessidade real.

Java | Python | SQL Ver repositório no GitHub
PROJETO 02 | PROJETO ACADÊMICO

Portal Helpdesk

Sistema web desenvolvido durante o último bimestre do curso Técnico em TI, com o objetivo de facilitar o gerenciamento de chamados de suporte técnico.

O projeto aplica conhecimentos de programação e banco de dados para organizar solicitações, acompanhar atendimentos e melhorar o controle dos serviços de suporte.

Python | Banco de Dados | Desenvolvimento Web Ver repositório no GitHub
